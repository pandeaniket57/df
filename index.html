Google Apps Script Web App Endpoint

To connect this frontend directly to your Google Sheets database, deploy the following Google Apps Script as a Web App:

  1. Create a Google Sheet and open Extensions → Apps Script.
  2. Paste the project’s Code.gs, run setupSheets and authorizeIntegrations, and approve the requested Sheets, email, and Drive permissions.
  3. Share the spreadsheet with pandeaniket57@gmail.com as an Editor. Keep general access set to Restricted; the web app must not replace the Sheet’s own sharing permissions.
  4. Update the Orders tab’s Status cell to Ordered, Packed, In Transit, Out for Delivery, Delivered, or Cancelled. Customers see the latest stage when they track the order.
  5. For the Admin-tab sign-in, create a Google OAuth Web application client ID in Google Cloud Console, add your published website origin under Authorized JavaScript origins, and set it as APP_CONFIG.googleClientId below.
  6. In Apps Script project settings, add ADMIN_EMAIL as pandeaniket57@gmail.com.
  7. Fill the Products tab with columns ProductID, Name, Price (per kg), Category, Description, Image, Badge, Active. Put multiple image URLs in Image separated by a vertical bar (|). Square images around 800 × 800 px work best. The UPI ID and WhatsApp number are saved in this browser’s admin settings.
  8. For the catalog to load from the Sheet for every visitor, set appsScriptUrl in APP_CONFIG in this HTML file before publishing. The browser-only URL setting below is for testing this device.
  9. Deploy as a Web App, execute as you, grant access to anyone, then paste the /exec URL below. Keep the spreadsheet itself private.

Privacy: Share the Sheet only with authorized Gmail accounts. The Admin-tab sign-in is a browser UI gate, not a security boundary; anyone with developer tools can bypass a static-page gate. The Apps Script endpoint is public for customer catalog/order flows, so do not add customer-list or admin-data APIs to it.

Apps Script sends order-received emails. Orders below ₹500 include ₹50 shipping; shipping is free at ₹500 and above. Every UPI order must include a JPG, PNG, or WebP payment screenshot (up to 500 KB), saved to a private Drive folder and linked in the store notification email; the UTR is optional. After updating the script, rerun setupSheets and authorizeIntegrations, then deploy a new web app version. A submitted UTR or screenshot is not payment verification and is never marked paid automatically. WhatsApp opens a pre-filled message; unattended delivery requires a separate WhatsApp Business API provider.
